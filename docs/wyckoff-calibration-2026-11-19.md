样本外结论：

- **Spring 校准有效**：验证段从 1 个样本、1.49% 提升到 5 个样本、3.86%，胜率 100%。
- **SOS 放宽无效**：如果同时放宽 SOS（`volZ 0.5→0`、`breakAtr 0.3→0.2`），样本外验证均收益从 2.26% 降到 0.56%，训练段从 0.62% 变为 -0.43%。因此 **SOS 阈值恢复旧值**。

- 最终参数在样本外把入场样本从 164/82 提升到 224/122，训练段均收益 0.01% → 0.06%，验证段 1.23% → 1.04%，胜率持平。属于“样本更多、单笔收益略低但更稳健”的取舍。

## 结论

1. **Spring 是最稳定的多头入场事件**：校准集 19 个样本、样本外 13 个样本；平均收益与胜率均为正，样本外验证段尤其明显。
2. **SC 有稳定正向漂移**，但它是“观察/潜在反转”事件，不建议单独入场；适合作为 Spring/ST/SOS 的前置背景。
3. **SOS 依赖市场环境**：2024–2026 强势段很好，其他阶段偏弱；且放宽阈值在样本外变差。保留严格阈值，并要求周线趋势、相对强弱或 LPS 确认。
4. **LPS / ST 单独入场偏弱**：更适合作为 Spring/SOS 之后的确认与止损参考，而不是独立触发。
5. **UTAD / SOW / BC 作为“卖出/做空”信号在 ETF 上不可靠**：样本内前向收益多为正。长多策略应依赖**结构止损/移动止损**，把派发事件作为风险提示而非自动清仓指令。
6. **样本量仍然偏小**（最终参数 Spring 校准集 19 + 样本外 13），应每季度复跑，并逐步扩展到更多 ETF。

| `spring.maxBreakAtr` / `confirmBars` | 0.5 / 3 | 1.0 / 5 |
| `utad.maxBreakAtr` / `confirmBars` | 0.5 / 3 | 1.0 / 5 |
| `sos.volZ` / `sos.breakAtr` | 0.5 / 0.3 | **保持 0.5 / 0.3**（放宽在样本外变差） |
| `sow.volZ` / `closePos` / `breakAtr` | 1.0 / 0.3 / 0.3 | **保持 1.0 / 0.3 / 0.3**（放宽在样本外变差） |
| `range.sideLookbackBars` / `sideMinReturn` | 无 | 60 / 5% |

区间默认（`minBars=20`、`maxWidthAtr=3.0`、`minTouches=2`）保持不变：单独放宽区间会显著增加 SOS/LPS 数量，但训练段与样本外质量下降，因此没有采用。

## 使用建议

- 默认策略优先使用 **Spring + 阶段 C/D + 周线背景**；
- SOS 作为第二类入场，但必须叠加周线趋势/相对强弱/LPS 确认，不单独使用；
- LPS/ST 作为确认与止损位，不单独触发；
- 出场以结构止损为主，UTAD/SOW 仅作为风险提示；
- 任何参数改动都在研究页用训练/验证两段做对照，并额外跑上证指数 + 未参与校准的 ETF。
